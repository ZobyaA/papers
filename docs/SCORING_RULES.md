# Fab Scoring Rules

程序根据 AI 输出的 Q2~Q6 判定自动计算分数。修改此表即可改变评分规则，无需修改 prompt。

## 分数映射表

| 维度 | 判定值 | 分值 | 说明 |
|------|--------|:----:|------|
| **Q2 直接工艺** | YES | +5 | 核心贡献是 SC qubit 芯片制造/加工/表征 |
| | NO | 0 | |
| **Q3 工艺可迁移** | 强可迁移 | +4 | 技术可直接用于 SC qubit 芯片制造 |
| | 中可迁移 | +2 | 有明确迁移路径，非量子计算语境 |
| | 弱可迁移 | +1 | 远期启发价值 |
| | NO | 0 | |
| **Q4 量子硬件相关性** | 直接相关 | +2 | 研究的器件/系统是 SC 量子计算核心元件 |
| | 临近相关 | +1 | SC/低温电子学领域，与量子计算临近 |
| | NO | 0 | |
| **Q5 实验验证** | YES | +2 | 有实测数据、器件照片、SEM/TEM等 |
| | 部分 | +1 | 仿真为主，有部分实验验证 |
| | NO | 0 | 纯理论/仿真/综述 |
| **Q6 领域偏离** | 完全无关 | -5 | 纯算法/纯理论/超材料/天体物理等 |
| | 远缘 | -2 | 量子/SC理论但无工艺/器件制造 |
| | NO | 0 | |

## 计算公式

```
raw = Q2_val + Q3_val + Q4_val + Q5_val - Q6_val
final = min(raw, 10)   # 上限 10 分
```

分数范围: **-5 ~ 10**

## 分数含义

| 分数 | 含义 |
|:----:|------|
| 8~10 | 核心 fab 论文，直接制造/加工 SC qubit 芯片 |
| 5~7 | 强关联，工艺/材料可直接迁移 |
| 3~4 | 中等关联或边缘相关，有参考价值 |
| 1~2 | 弱关联，供人工快速浏览 |
| ≤0 | 与 SC qubit 芯片制造无关，排除 |

## 修改指南

- **想保留更多边缘论文**：降低 Q3 弱可迁移的判断门槛，或提高弱可迁移分值(+1→+2)
- **想更严格排除噪音**：扩大 Q6 完全无关的覆盖范围，或提高扣分(-5→-7)
- **想强调实验数据**：提高 Q5 分值(+2→+3)
- **调整评分阈值**：修改 `min_score` 参数（`retrieve_fab.py` 的 `main()` 中）
